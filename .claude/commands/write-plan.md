# /write-plan

## Quick Reference

| Item | Value |
|------|-------|
| Purpose | Create implementation plans |
| Prereq | Design completed (via /brainstorm or spec) |
| Output | Plan file with numbered tasks |
| Skill | `writing-plans` |

## When to Use

- After brainstorming/design is complete
- When you have clear requirements to implement
- Before starting multi-step implementation work
- When handing off to another session or agent

## What It Does

1. **Review requirements** - Understand scope and constraints
2. **Create tasks** - Numbered, sequential, bite-sized
3. **Include verification** - Each task has done criteria
4. **Document dependencies** - File paths, test commands
5. **Write plan** - To file or directly in session

## Output Format

Plans include for each task:
- Task number and title
- Exact file paths to modify
- Code changes or patterns to follow
- Verification command/criteria
- Done criteria

## Process

Use the writing-plans skill exactly as written.
