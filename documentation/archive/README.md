# Documentation Archive

This directory contains archived documentation that has been superseded by consolidated versions or is no longer actively maintained but kept for historical reference.

## Purpose

The archive serves to:
- Preserve historical documentation and analysis
- Reduce clutter in the main docs/ directory
- Maintain a clear separation between active and archived documentation
- Enable future reference to previous iterations of analysis and planning

## Structure

```
archive/
├── 2025-11/              # November 2025 archives
│   ├── sprints/          # Archived sprint documentation
│   ├── reports/          # Archived progress reports
│   ├── analysis/         # Archived analysis documents
│   └── tests/            # Archived test coverage documentation
└── [YYYY-MM]/            # Future monthly archives
```

## Archive Policy

Documents are archived when:
1. **Consolidation**: Multiple related documents have been merged into a single comprehensive version
2. **Supersession**: A newer version or approach has replaced the old documentation
3. **Completion**: Sprint or time-bound documentation is no longer active
4. **Redundancy**: Content is duplicated elsewhere in a more organized format

## Accessing Archived Documents

All archived documents are retained in git history and can be:
- Browsed directly in this directory structure
- Referenced via relative paths from active documentation
- Retrieved from git history if needed

## Active Documentation

For current, actively maintained documentation, see:
- `/docs/testing/` - Current test coverage and testing guides
- `/docs/analysis/` - Active analysis and findings
- `/docs/sprints/` - Current sprint planning and execution
- `/docs/progress-reports/` - Active progress reports

## Archive Date Format

Archives are organized by year-month (YYYY-MM) to maintain chronological order and enable easy identification of when documents were archived.

---

**Note**: Archived documents are kept for reference only. Always refer to the active documentation in the main `/docs` directory for current information.
